# LumeTask Android releases

Download signed Android APKs from [Releases](https://github.com/crystal-norway/lumetask-releases/releases). Each release includes notes and checksums.

The [website download page](https://lume-task.pages.dev/download/) is a permanent link to Releases. APKs and release notes are maintained on GitHub only.

This repository contains public distribution files only. LumeTask application source code, private settings, credentials and user data are not included. New accounts require administrator approval during public preview.

Debug and release builds use different signing certificates. Sync all data before migrating.
