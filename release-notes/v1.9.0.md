# LumeTask v1.9.0

本版补齐邮箱账号管理，并提供使用长期发布签名的 Android 安装包。安装包、完整更新日志和校验文件统一在此发布；官网下载页作为固定入口。

## 新增

- **邮箱与 GitHub 登录**：首次验证可创建账号，管理员审核通过后使用；设置中可将邮箱与 GitHub 绑定到同一个 LumeTask 账号。
- **密码管理**：邮箱首次设密、密码登录、修改密码和通过邮箱验证码重置密码。
- **正式签名安装包**：后续使用相同发布签名的新版本可覆盖升级。

## 修复

- **账号切换**：不同账号使用各自的本地数据库，保留原账号的数据和待同步操作。
- **验证码错误提示（服务端）**：区分不匹配、过期、重发替代、次数耗尽和登录服务异常。现有 Android 安装包无需更新即可获得更明确的提示；已审核但未设密码的账号仍可通过验证码登录。

## 升级说明

- 支持 Android 8.0 及以上。
- 旧调试测试包与正式包的签名不同，无法直接覆盖安装。请先在旧版确认数据已同步；存在待处理操作时先导出并保留旧版。确认云端数据完整后，再卸载旧调试包、安装正式包，并使用同一账号登录恢复数据。
- 已安装正式签名版本的用户无需重新安装来获得上述服务端验证码提示修复。
- 当前为公开内测，新账号需管理员审核。
