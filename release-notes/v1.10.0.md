# LumeTask v1.10.0

本版补齐设置中心，将账号安全、偏好、数据管理与桌面入口集中到统一页面。支持任务与计时数据导出、项目和视图管理，并改进桌面小组件及快捷计时的可靠性。

## 新增

- **设置中心**：按账号管理、偏好、数据管理、快捷功能与桌面小组件分组。
- **主题和默认视图**：白天、黑夜、跟随系统；任务默认视图支持任务、四象限、看板、日历，计时默认视图支持经典 3 日、经典 1 日、点阵、记录。
- **默认计时颜色**：支持预设色、RGB 和 HEX，无有效项目颜色时使用设定颜色。
- **数据导出**：任务和计时可导出 CSV / JSON，包含本机未同步改动与已完成记录，排除已删除数据。导出用于查看和留存，暂不提供导入恢复。
- **项目管理**：新建、改名、调色、删除确认、复制 NFC 链接，以及是否在新计时选择器中显示。
- **四象限与看板管理**：修改象限名称与颜色；新建、改名或删除看板列，默认列受到删除保护。
- **账号解绑与注销**：邮箱和 GitHub 可解绑，至少保留一种可用登录方式；注销需身份验证并输入确认文字。最后一位有效管理员受到注销保护。
- **桌面与通知栏入口**：可请求添加打开任务、打开计时、开始空白计时、停止计时四个快捷方式，今日待办及习惯打卡小组件，以及通知栏空白计时开关。

## 变更

- **账号安全**：解绑会撤销其他设备会话；解绑邮箱也会移除该邮箱的登录密码。已设密码时验证原密码，无密码时要求近期邮箱或 GitHub 验证。
- **注销范围**：删除当前账号的云端数据和执行注销设备的本机数据，其他设备登录失效；不远程擦除其他设备离线副本或用户主动导出的文件。再次注册需重新审核。
- **项目可见性**：仅影响当前账号、当前设备的新计时选择；历史记录和统计保留，编辑原已绑定的隐藏项目时仍可选。
- **小组件更新**：数据变化后自动刷新，退出、切换账号或云端恢复尚未完成时隐藏旧内容；新版 Android 使用直接列表接口。

## 修复

- **快捷计时重复执行**：页面重新创建后不再重复开始或停止计时。
- **冷启动停止计时**：直接读取运行记录，避免界面尚未加载时停止无效。
- **习惯小组件点击**：修复列表按钮的打卡传递，并校验账号归属，防止旧组件操作写入新账号。
- **看板删除**：在确认时重新检查默认列状态，删除普通列后保留任务并回落显示。

## 升级说明

- 支持 Android 8.0 及以上。已安装正式签名 v1.9.0 的用户可直接覆盖升级，保留本机数据，无需卸载。
- 旧调试包若签名不同，无法直接覆盖；请先确认同步完成，并导出未同步数据，再迁移到正式包。独立 QA 包可共存，其本机数据不会自动复制到正式包。
- 账号解绑与注销所需服务端更新已上线；要使用本版完整设置及桌面入口，需要安装新 APK。
- 当前为公开内测，新账号仍需管理员审核。手机、微信、QQ 登录及设置中的习惯管理仍为开发中入口。
- 桌面添加需要系统确认，不同厂商桌面和通知栏行为可能不同；不支持时可按提示手动添加。本轮设备验收使用 Android 16，旧系统兼容分支尚未逐一实机覆盖。
