# LumeTask v1.11.0

本版新增启动公告与管理员内容投送。可设置接收账号、日期和每日次数，弹窗文案支持后台编辑，无需为每次文字调整重新安装 App。

## 新增

- **公告管理**：创建文字公告或交互内容卡片，选择全部已批准账号或指定账号，设置开始、结束日期、每日次数及启用开关。
- **自定义内容**：弹窗顶部标题、正文、各阶段提示、按钮与无障碍说明均可由管理员编辑，支持称呼变量。
- **交互内容卡片**：支持内容展开、重播与关闭，适配不同屏幕尺寸。

## 变更

- **启动时机**：登录获准、首次云端恢复完成并进入主页后获取公告；获取失败不影响正常使用。
- **频率控制**：按北京时间统计每日额度，跨设备共用；同一次 App 进程中的页面切换、旋转和普通后台返回不会额外计次，网络重试保持幂等。
- **定向投送**：服务端核对接收账号，不向其他账号返回私人内容。切换账号后丢弃旧账号尚未完成的内容请求。
- **有效期**：开始时刻生效，结束时刻停止投送；管理端选择的结束日期包含当天。编辑公告不会清空已消耗次数。

## 升级说明

- 支持 Android 8.0 及以上；正式签名 v1.10.0 可直接覆盖升级，无需卸载。
- 需要安装本版才能收到公告。服务端与管理页面更新已单独部署。
- 每日次数统计冷启动进入主页时的投送机会，App 关闭时不会自行弹窗；离线时仍可正常使用原有功能。
- 正式版不展示调试实验入口。
