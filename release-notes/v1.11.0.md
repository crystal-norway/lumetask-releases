# LumeTask v1.11.0

本版新增可由管理员投送的启动公告与交互生日卡。指定账号、日期和每日次数，弹窗中的文字可在管理后台修改，无需为每次文案调整重新安装 App。

## 新增

- **公告管理**：管理员可创建文字公告或生日祝福，选择全部已批准账号或指定账号，设置开始、结束日期、每日次数及启用开关。
- **交互生日卡**：温暖烛光风格，点击礼物盒后，草莓、生日蛋糕和橡皮小黄鸭同步弹出，支持重播与关闭。
- **全部文案可编辑**：顶部标题、祝福称呼、正文、播放过程提示、按钮及无障碍说明均由管理员设置，支持用 `{name}` 代入称呼。

## 变更

- **启动时机**：登录获准、首次云端恢复完成并进入主页后获取公告；获取失败不影响正常使用。
- **频率控制**：按北京时间统计每日额度，跨设备共用；同一次 App 进程中的页面切换、旋转和普通后台返回不会额外计次，网络重试保持幂等。
- **定向投送**：服务端核对接收账号，不向其他账号返回私人公告。切换账号后丢弃尚未完成的旧账号公告请求。
- **有效期**：开始时刻生效，结束时刻停止投送；管理端选择的结束日期包含当天。编辑公告不会清空已消耗次数。

## 升级说明

- 支持 Android 8.0 及以上；正式签名 v1.10.0 可直接覆盖升级，无需卸载。
- 需要安装本版才能收到公告；旧版不具备公告播放器。服务端与管理页面更新已单独部署。
- “每日次数”统计冷启动进入主页时的投送机会，App 关闭时不会自行弹窗。离线时仍可正常使用原有功能。
- 生日实验区只保留在调试构建中，正式版不展示实验入口。
